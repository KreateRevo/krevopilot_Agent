# Security

The KrevoPilot Agent is designed to run with read-only Kubernetes permissions.

It does not request permission to read Kubernetes Secrets, and regular snapshots do not collect raw logs or environment variable values.

On-demand log access is optional and disabled by default. When enabled, the
agent may request `pods/log get` and fetch only a specific pod/container/time
window requested by an authorized user. Log text must be redacted inside the
cluster before it is sent to KrevoPilot.

If you find a security issue, contact the KreateRevo team privately before opening a public issue.

Recommended production settings:

- Use HTTPS for `PLATFORM_URL`
- Keep `VERIFY_TLS=true`
- Use a unique one-time `AGENT_KEY` generated by KreateRevoPilot for each cluster
- Use a unique `HASH_SALT` per customer or cluster
- Rotate `AGENT_KEY` if it is exposed
- Use `EVENT_MESSAGE_MODE=summary` or `none` for stricter privacy environments
- Use `PRESERVE_NAMESPACES=false` if namespace names are sensitive
- Keep `LOGS_ENABLED=false` unless the customer explicitly wants live log viewing
- Use `LOG_STORAGE_MODE=none` by default; save only short sanitized evidence snippets when needed
- Enable the Helm chart NetworkPolicy and restrict egress to your KreateRevoPilot endpoint CIDRs where supported by your CNI
- Pin the agent image by digest for production change control

Data collection summary:

- Collected in snapshots: pod health/status, restart counts, warning event reason/message according to privacy mode, node health/capacity, resource requests/limits, Metrics Server CPU/memory usage.
- Optional on-demand only: redacted pod logs for a specific pod/container/time window when `LOGS_ENABLED=true`.
- Not collected: Kubernetes Secrets, ConfigMaps, raw logs in regular snapshots, environment variable values, full object manifests, shell access, exec access.
- Aliased by default: pod names, node names, workload names, container names, involved object names.
- Namespace names are preserved by default for usability, but can be aliased with `PRESERVE_NAMESPACES=false`.

Log storage recommendation:

- Default: no raw log storage.
- MVP investigation: save only selected sanitized snippets as evidence.
- Enterprise/history: use customer-owned Loki, OpenSearch, Splunk, Datadog, S3, or MinIO and store only references/queries in KrevoPilot.
